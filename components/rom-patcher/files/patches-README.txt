ROM-HACK PATCHES
================
Drop a patch file here and it is applied the next time Batocera starts
(or straight away if you use "batocera-add" on the PC).

.bps / .ups   Just drop it in. The right game is found automatically.
.ips          Name it after the game file, e.g. for roms/snes/Cool Game.sfc
              use "Cool Game - Hard Mode.ips".

Your original game is never changed. A patched copy appears beside it,
named after the patch. Used patches move to "applied"; problems are
written to patch-log.txt. Refresh the game list afterwards:
Start > Game settings > Update gamelists.
